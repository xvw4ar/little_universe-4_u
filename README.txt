LITTLE UNIVERSE
===============

Upload index.html, style.css, and script.js to the root of a GitHub Pages repository.

Features:
- English-only interface
- ENTER opening screen
- Night City-inspired CSS skyline and Arasaka sign
- Birthday letter
- Hidden messages archive: 14 unique fragments per browser/device, no repeats until all are found
- Final 15th message with a decryption animation
- No music player, audio files, song names, or music controls

Note: Hidden-message progress is saved in the visitor's browser using localStorage.
